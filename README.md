# NuvoTracker

Make a simple expense tracker app where users can add, edit and delete expenses. Each expense should have a description, amount, category and date. Store all expenses in a database and display the total amount spent.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://nuvotracker.lovable.app
